# Frontend — Etkinlik Rezervasyon Sistemi

React 19 + TypeScript + Vite. Kurulum, mimari ve genel açıklama için kök dizindeki [README.md](../README.md) dosyasına bakın.

```bash
npm install
npm run dev      # http://localhost:5173 — /api ve /hubs, VITE_API_TARGET'a (varsayılan http://localhost:5001) proxy'lenir
npm test         # Vitest
npm run lint
npm run build
```
